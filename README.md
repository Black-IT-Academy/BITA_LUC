# BITA Linux Challenge 🐧

**Black IT Academy's community-powered run of the [Linux Upskill Challenge](https://linuxupskillchallenge.org)** — 20 hands-on lessons, 30 days, a real server you build, run, and bring back to life. Together.

**Cohort 1: September 14 → October 15, 2026** · Kickoff call: Saturday, Sept 12, 12PM ET

1. **[Setup.md](Setup.md)** — get your Linux server running (cloud VPS or free local VM) *before Day 1*

3. **[Lessons](https://linuxupskillchallenge.org)** — the curriculum itself lives on the Linux Upskill Challenge site. Day 1 starts Sept 14
4. **[capstone/](capstone/)** — the Terraform that builds the Firefight environment. For the volunteers who run a cohort; as a participant you're handed a VPN profile and never touch this

## How this repo works

This is the reference shelf, not the conversation. Everything you need to *start* lives here; everything that happens *during* the challenge — questions, screenshots, war rooms, wins — happens in the **BITA Discord**, in **#kernel-crew*. To join the server is free, the challenge is free - just like everything BITA does.

## Your own repo

Every participant keeps a **challenge journal repo** on GitHub from Day 1 — your notes, your configs, and every problem you hit and fixed. It becomes your interview receipts, and it's your ticket into the Firefight capstone. [SETUP.md](SETUP.md#step-3--create-your-challenge-journal) walks you through creating it in five minutes, even if this is your first time on GitHub. (If reading this repo is your first time on GitHub — welcome. You're already doing it.)
